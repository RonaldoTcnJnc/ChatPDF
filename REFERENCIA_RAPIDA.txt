INICIO RÁPIDO
=============

1. Coloca PDFs en ./pdfs/
2. Asegúrate que LMStudio esté en localhost:1234
3. Ejecuta:
   
   python quick_start.py


ARCHIVOS POR PROPÓSITO
======================

QUIERO EMPEZAR YA:
  → python quick_start.py

QUIERO APRENDER PRIMERO:
  → python tutorial.py

QUIERO VER EJEMPLOS:
  → python example_usage.py

QUIERO USAR PROGRAMÁTICAMENTE:
  from chatbot_rag import ChatbotRAG
  chatbot = ChatbotRAG()
  chatbot.load_pdfs("./pdfs")
  response = chatbot.get_response("Mi pregunta")


COMANDOS EN CHAT
================

salir           Termina sesión
limpiar         Limpia historial
stats           Muestra estadísticas
cargar /ruta    Carga PDF específico
cargar /carpeta Carga todos los PDFs


ESTRUCTURA
==========

chatbot2/
├── quick_start.py        ← COMIENZA AQUI

├── tutorial.py           Tutorial interactivo
├── example_usage.py      Ejemplos de uso

├── SETUP.md              Guía de instalación
├── config.json           Configuración
├── chroma_db/            BD vectorial
└── pdfs/                 Tus PDFs aquí


PARAMETROS CLAVE (config.json)
==============================

chunk_size: 500           Tamaño de fragmentos
chunk_overlap: 100        Solapamiento
retrieval_k: 3            Documentos a recuperar
embeddings_model: ...     Modelo de embeddings
temperature: 0.7          Creatividad


ERRORES COMUNES
===============

"base_url not reachable"
→ Verifica LMStudio en localhost:1234

"No hay información en BD"
→ Coloca PDFs en ./pdfs/ y reinicia

"Embeddings lentos"
→ Normal la primera vez (~90MB descarga)

"Memoria llena"
→ Limpia ./chroma_db/ y recarga PDFs


PREGUNTAS TIPICAS
=================

¿Funciona offline?
→ Sí, después de descargar modelos (primera vez)

¿Es privado?
→ Sí, todo local en tu PC

¿Qué modelos de embeddings hay?
→ all-MiniLM-L6-v2 (rápido), all-mpnet-base-v2 (preciso), etc.

¿Puedo mejorar precisión?
→ Aumenta retrieval_k, usa mejor modelo embeddings
